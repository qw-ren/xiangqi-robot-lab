# 核心文件与运行流程

## 策略项目：优先看这六处

| 路径（位于xiangqi_strategy） | 职责 |
| --- | --- |
| app.py | 创建同一个Game，接入轻量网页与可选串口线程 |
| board.py | 坐标/FEN转换、规则复核、推断人的合法一步 |
| engine.py | 通过UCI管道启动Pikafish并读取bestmove；它自身不是搜索引擎 |
| game.py | 对局状态、AI请求、待执行计划、ACK/DONE与视觉确认、重复请求与超时 |
| protocol.py | JSON帧、CRC32、LF分帧与响应压缩 |
| static/index.html | 轻量棋盘、按钮和状态轮询 |

默认虚拟局：网页走棋→app→game/board复核→engine调用Pikafish→合法AI走法→提交Game→网页读取新状态。

真实接口：队友全盘→串口app/protocol→game/board判断人的走棋→总体控制器主动ai→PLAN→控制器执行并返回ACK/DONE→动作后新视觉observe→全盘一致后提交。策略服务本身没有直接Arm_Lib执行器，不会收到observe就自动搜索。

PLAN中的pieces是预测结果，正式state.pieces是已提交结果。没有执行后视觉确认时，不能把预测结果当作实际棋盘。

## 完整网页：保留模块的原因

| 路径（位于chch-robot） | 职责 |
| --- | --- |
| run_local.py、config.py | 跨平台入口、引擎路径与各项配置 |
| web_simulation/app.py | 创建Flask应用和唯一game_state |
| web_simulation/routes/ | 页面API、对局、摄像头、识别和AI请求 |
| web_simulation/domain.py、game_logic.py | 棋盘/FEN工具和状态提交 |
| web_simulation/services.py | 按需创建引擎和识别器 |
| web_simulation/templates/、static/ | 页面HTML、CSS、JS，缺失会白屏或按钮失效 |
| ai/、local_engine_io.py | 真实Pikafish的UCI输入输出 |
| chro_web_tools.py、xq_utils/ | 规则复核、坐标、FEN和记谱 |
| dofbot_web.py | 将网页动作接到DOFBOT，等待动作及视觉核对后提交 |
| dofbot_adapter.py | Arm_Lib六轴写入、反馈、取放、吃子及电磁铁 |
| robot/ | 当前网页仍导入的协议与控制类；即使选DOFBOT也不能直接删 |
| vision/、core/ | 相机、稳定判断及ONNX推理，网页仍有导入依赖 |
| model/pose/4_v6-0301.onnx | 当前角点识别模型 |
| model/layout_recognition/nano_v3-0319.onnx | 当前全盘分类模型 |
| watch_service.py、stop_local.py | 守护工具与正常停止入口；不是已安装好的Linux自启服务 |

完整网页真实流程：相机→稳定局面/合法人的走棋→Pikafish→规则复核→DOFBOT计划及执行→新鲜稳定全盘确认→正式FEN、网页和历史一起更新。mock模拟模式不驱动硬件。

## 包根目录与附加工具

- pi_project.py：检测依赖、路径、引擎格式，执行--search并启动所选项目。
- setup_pi.sh与requirements清单：安装依赖；程序运行时不导入这些文件，但部署时需要。
- engine_assets/pikafish.nnue：匹配权重；还要放入Linux ARM引擎pikafish。
- tools/one_step.py与examples/start.json：--search实际使用，不能当成无用示例删除。
- tools/serial_peer.py：恢复的串口干跑工具，用模拟ACK/DONE/视觉验证协议。不能用它确认真实机械臂已完成动作。
- chch-robot/main.py、cli/、game_manager/：恢复原项目命令行兼容入口；当前推荐流程仍是pi_project.py。旧命令行不是你们DOFBOT闭环的替代入口，实际相机/运动子命令本次未实测。

不要随意删除__init__.py，它们参与Python包导入。程序运行后生成__pycache__是正常现象，可清理，会再生成。

data目录会在运行后创建，可能包含日志、服务凭据及现场标定。以后不能把整个data都当作垃圾删除；迁移前先备份真实标定文件。模拟角度不能用于实体。
