## 不能由本次验证得出的结论

本次不证明树莓派ARM引擎、Arm_Lib、串口设备、实际相机精度和真实90格抓放均已成功。ARM引擎、厂商库、现场标定仍需准备；测试所用Windows引擎不放入包中。
